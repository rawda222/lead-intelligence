# Lead Conversion Intelligence

Predict which CRM leads will become customers, explain why, recommend actions, estimate time-to-close and
expected revenue. **Status: Week 1 of 4 (data and analysis) is done. Models, API and dashboard come next.**

> **Data is synthetic.** It is generated by [leadforge](https://github.com/leadforge-dev/leadforge)
> (open source, MIT). All numbers describe the simulator, not real sales behavior. The pipeline is built so a
> real CRM export can replace it.

## Quick start (needs Python 3.11+)

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m src.data.generate        # 1) generate raw tables (seed 42, research_instructor mode)
python -m src.data.build_master    # 2) one row per lead + snapshot-safe features + data dictionary
python -m src.analysis.eda         # 3) KPIs, 11 charts, reports/week1/EDA_REPORT.md
pytest -q                          # 4) integrity and leakage tests
```

## Key design decisions

* **Status** is taken from the final pipeline stage: Won = `closed_won`, Lost = `closed_lost`, Open = anything else.
  Models train on Won/Lost only and score Open leads.
* **Leakage control.** leadforge's `research_instructor` tables contain the full timeline (about 89 days).
  Features (`snap_*`) only use events within **30 days of lead creation**. Closing dates, final stage and
  durations are outcome-only. A test recomputes the counts from raw data and proves the window matters.
* **`research_instructor` mode is required** for closing dates. The public `student_public` mode hides them and
  its `opportunities.stage` column leaks the label.
* `is_sql` is excluded from features until its timing is verified.
* `owner_rep_id` is kept for analysis only. The model will be tested with and without it.

## Known limits (be upfront about these)

* Synthetic data, so results show the method, not Rootk's real performance.
* Durations are capped at about 90 days by the simulator's window (Won leads pile up near the cap).
* No stage history, only 2 regions (UK, US), 4 industries, all leads created in one month, no churn.
* Open leads look more like Won leads than Lost leads on first-30-day activity, so a model trained on closed
  leads may face a shifted population when scoring Open leads (check in Week 2).
* Post-close feedback does not exist in leadforge. It will be simulated later and kept out of the model.
